# Project Title: Korea Covid-19 

### Description: 
Analysis of a COVID-19 dataset from the Korean CDC and local governments, examining how the timing of government policies and control strategies corresponded with trends in cases and deaths. Motivated by interest in Korea's comparatively non-authoritarian but effective pandemic response relative to other Asian countries.

### Approach
* Data cleaning and exploratory analysis conducted in Jupyter (covid.ipynb) using pandas and numpy, including handling of missing/grouped age categories and merging case data with policy timeline data
* Reusable visualization functions (covid_fns.py) built to standardize chart formatting (age/sex breakdowns, policy timing overlays) across multiple analyses in the notebook. Visualized policy timing against case/death trends to identify potential associations

### Contents
* Project code housed in Jupyter notebook
* Additional functions file available in covid_fns.py file

### Files
* Main project file: covid.ipynb
* Functions: covid_fns.py
